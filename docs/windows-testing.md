# Δοκιμή σε πραγματικό PC με Windows 10/11

Το CI χτίζει το `NetWatch.exe` και ελέγχει ότι το backend ξεκινά σε demo. Όσα ακολουθούν θέλουν όμως αληθινό
μηχάνημα: tray, παράθυρο Edge, Npcap, firewall, ειδοποιήσεις. Σημείωσε ✅ / ❌ και, για κάθε ❌, κράτα τις
τελευταίες γραμμές από το `%LOCALAPPDATA%\NetWatch\netwatch.log`.

Πρώτα σημείωσε: έκδοση Windows (`winver`), γλώσσα συστήματος, Wi‑Fi ή καλώδιο, έκδοση Npcap.

## 1. Εγκατάσταση και πρώτη εκκίνηση
- [ ] Κατέβασε το `NetWatch-windows-x64.zip` από το [τελευταίο release](https://github.com/Gyuri1999/netwatch/releases/latest) και αποσυμπίεσέ το (όχι μέσα από το zip).
- [ ] Διπλό κλικ στο `NetWatch.exe`. Το SmartScreen ρωτά μία φορά: *Περισσότερες πληροφορίες → Εκτέλεση οπωσδήποτε*.
- [ ] Εμφανίζεται ασπίδα στο tray (ίσως κάτω από το βελάκι ^).
- [ ] Ανοίγει μόνο του παράθυρο Edge (χωρίς γραμμή διευθύνσεων) με τον πίνακα.
- [ ] Δεύτερο διπλό κλικ στο `NetWatch.exe`: **δεν** ανοίγει δεύτερο NetWatch, απλώς ξαναβγαίνει το παράθυρο.

## 2. Demo (χωρίς Npcap)
- [ ] Tray → Demo: γεμίζει ο χάρτης με τόξα και έρχονται ειδοποιήσεις.
- [ ] Η ασπίδα αλλάζει χρώμα (πράσινο → κίτρινο/κόκκινο) και δείχνει αριθμό ειδοποιήσεων.
- [ ] Εμφανίζεται ειδοποίηση των Windows (toast) για σοβαρή ειδοποίηση.
- [ ] Γλώσσα: το κουμπί EL/EN αλλάζει όλο το περιεχόμενο, και τις εξηγήσεις στις κάρτες.

## 3. Live με Npcap
- [ ] Χωρίς Npcap: Tray → Live προτείνει να ανοίξει η σελίδα λήψης του Npcap.
- [ ] Εγκατέστησε το [Npcap](https://npcap.com/#download) (προεπιλογές) και ξαναδιάλεξε Live.
- [ ] Βλέπεις την κίνηση του PC (άνοιξε 2–3 sites) και τις συσκευές του δικτύου στη λίστα.
- [ ] Σωστά router (gateway), IP και DNS server στις πληροφορίες δικτύου.
- [ ] Αν το Npcap εγκαταστάθηκε με *Restrict to Administrators*: λειτουργεί μόνο το «Live ως διαχειριστής».

## 4. Live ως διαχειριστής και αποκλεισμός
- [ ] Tray → Live ως διαχειριστής: εμφανίζεται UAC και μετά ο πίνακας κανονικά.
- [ ] Σε μια ειδοποίηση, **Block** → στο *Windows Defender Firewall → Advanced settings → Outbound rules* υπάρχει κανόνας `NetWatch block <ip>`.
- [ ] Κλείσιμο από το tray (Έξοδος) → ο κανόνας έχει φύγει.

## 5. Wi‑Fi Guard (σε Wi‑Fi)
- [ ] Τρέξε τον έλεγχο: σωστό όνομα δικτύου και τύπος κρυπτογράφησης (WPA2/WPA3).
- [ ] Εμφανίζεται ο έλεγχος **DNSSEC** με αποτέλεσμα (όχι κενό ή σφάλμα).
- [ ] Σε δεύτερο δίκτυο (π.χ. hotspot κινητού) ο έλεγχος ξανατρέχει μόνος του σε live.

## 6. Αυτόματη εκκίνηση, αναβάθμιση, δεδομένα
- [ ] Tray → «Εκκίνηση μαζί με τα Windows» → επανεκκίνηση PC → η ασπίδα είναι στο tray.
- [ ] Απενεργοποίησέ το ξανά → μετά την επανεκκίνηση δεν ξεκινά.
- [ ] Αναβάθμιση: αποσυμπίεσε νεότερο zip πάνω από το παλιό → το ιστορικό ειδοποιήσεων και οι ρυθμίσεις μένουν.
- [ ] Έξοδος από το tray → δεν μένει `python.exe` του NetWatch στη Διαχείριση εργασιών.

## 7. Agent mode (το PC ως αισθητήρας για άλλες συσκευές)
- [ ] Από τον πηγαίο κώδικα (`git clone`, με Python 3.9+ εγκατεστημένη), σε PowerShell στον φάκελο: `.\run.bat --agent`. Τυπώνεται διεύθυνση `https://<ip>:8765/?token=…` και SHA-256 fingerprint.
- [ ] Από κινητό ή άλλο υπολογιστή στο ίδιο Wi‑Fi: η διεύθυνση ανοίγει (ο browser θα προειδοποιήσει για self-signed· το fingerprint πρέπει να ταιριάζει).
- [ ] Τα Windows ρωτούν για το firewall την πρώτη φορά: *Ιδιωτικά δίκτυα → Να επιτρέπεται*.

## Γνωστά κενά (όχι σφάλματα)
- Η σάρωση των κοντινών Wi‑Fi (κανάλια) δεν υπάρχει ακόμα στα Windows.
- Στο τερματικό της Ακαδημίας δεν υπάρχουν `dig` και `traceroute`.
